إنشاء مشروع جديد

من النموذج إلى ظهور المشروع في الفلاتر والمخزن والتكاليف والتقارير — مع عقد ومركز تكلفة مباشر.

أسهم لوحة المفاتيح للتنقل · F ملء الشاشة

1 — قائمة المشاريع قبل الإنشاء

شغّل npm run docs:demo-project
  • المكتب الفني → مشاريع
  • نقطة البداية قبل إضافة المشروع التجريبي

2 — تعبئة نموذج المشروع

بانتظار اللقطة
  • كود · اسم · عميل · حالة
  • بيانات تجريبية جاهزة للعرض
  • الحفظ يكتب في Postgres فوراً

3 — المشروع يظهر في القائمة

بانتظار اللقطة
  • بطاقة مشروع جديدة
  • جاهز للعقود وBOQ والمخزن

4 — إضافة عقد (مركز تكلفة)

بانتظار اللقطة
  • العقد = نطاق تشغيلي
  • يُزامَن مركز تكلفة مباشر تلقائياً

5 — الأثر: لوحة التحكم

بانتظار اللقطة
  • المشروع ضمن فلاتر المقارنة/الفترة

6 — الأثر: المخازن

بانتظار اللقطة
  • اختيار المشروع متاح
  • الخطوة التالية: ربط حساب 127…

7 — الأثر: التكاليف الفعلية

بانتظار اللقطة
  • فلتر المشروع/العقد للفواتير والمستخلصات

8 — الأثر: جداول الكميات

بانتظار اللقطة
  • يمكن اختيار المشروع وبدء البنود

9 — الأثر: المستخلصات

بانتظار اللقطة
  • نطاق العميل جاهز بعد العقد (+ بنود لاحقاً)

10 — الأثر: التقارير

بانتظار اللقطة
  • فلتر المشروع يشمل الكيان الجديد

خلاصة

  • إنشاء المشروع يفتح النطاق في كل الفلاتر فوراً
  • العقد يفعّل مركز التكلفة للتشغيل اليومي
  • لا أثر مالي في KPIs حتى فاتورة / صرف / مستخلص
