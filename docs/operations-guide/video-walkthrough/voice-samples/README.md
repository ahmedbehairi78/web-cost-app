# عيّنات الصوت لاستنساخ صوتك (ElevenLabs)

ضع هنا ملفات صوتية **بصوتك أنت** (موافقة قانونية مطلوبة — لا تستنسخ صوت شخص آخر دون إذن).

## المواصفات المفضّلة

- المدة الإجمالية: **1–2 دقيقة** (يمكن ملف واحد أو عدة مقاطع قصيرة)
- صيغ: `.mp3` / `.wav` / `.m4a` / `.ogg`
- جودة واضحة، بدون موسيقى خلفية قوية، تكلم بشكل طبيعي بالعربية
- مثال محتوى: اقرأ فقرة من دليل التشغيل أو صف خطوات إنشاء مشروع

## بعد وضع الملفات

1. أضف في `.env` (لا تلصق المفتاح في الشات):

```env
ELEVENLABS_API_KEY=sk_...
```

2. من جذر المشروع:

```powershell
npm run docs:voice:clone
```

سيُطبع `voice_id` — انسخه إلى `.env`:

```env
ELEVENLABS_VOICE_ID=...
```

3. ولّد التعليق ثم سجّل الفيديو:

```powershell
npm run docs:voice:narrate
npm run docs:video
```

الملفات في هذا المجلد **لا تُرفع إلى git** (محتوى صوتي شخصي).
