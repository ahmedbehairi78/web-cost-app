# سكربت إعلان ترويجي — Web Cost App (مقاولات)

**المدة المقترحة:** 100–115 ثانية (نسخة كاملة) · أو 45–60 ث (مختصرة)  
**النبرة:** عربية سهلة · قريبة من السوشيال · بدون مبالغة تقنية  
**الصوت:** نفس بصمة الصوت المستنسخة (ق→ء · بدون ترقيم في نص TTS)  
**المخرج:** فيديو قصير + لقطات حقيقية من التطبيق

---

## الفكرة في جملة

مش برنامج محاسبة عام ولا إكسيل مبعتر — ده نظام ** ادارة مقاولات بشكل كامل**: من المشروع والمخزن والمستخلص… لحد **توزيع التكاليف الخدمية، إقفال الفترات، البنوك، الرواتب، والتنبيهات** — بـ**صلاحيات حسب الدور**، واجهة **عربي/إنجليزي**، و**ثيمات** تناسب الشغل — والقيود بتتنشأ **بعد الاعتماد**.

## نص التعليق الكامل (نسخة سوشيال — للتسجيل)

> لو بتشتغل مقاولات الحسابات والمخزن والمستخلصات مش لازم تفضل مبعّترة  
> تبدأ بمشروع وعئد ومركز التكلفة بيتظبط من أول ما تحفظ  
> جدول الكميات مش أرقام بس كل بند يتربط بأصناف المخزن عشان الصرف يبقى مظبوط  
> فاتورة المشتريات بتدخل مخزن المشروع والصرف ينزل تكلفة فعلية على البنود  
> مستخلص العميل ب   جاهز للاستقطاعات والصافي بيحسب صح والقيد بعد الاعتماد  
> المصروفات الخدمية مش بتضيع بتتوزع على عئود المشاريع وبعد الاعتماد ينزل القيد  
> وفي إقفال للفترات المحاسبية وقفل الدفاتر عشان الشغل يبقى من الألف للياء  
> موديول البنوك يواكب التطور المصرفي حسابات وشيكات وتحويلات وإنستاباي مربوطة بالقيود  
> الرواتب على الأسلوب المصري أيام وتأمينات وضريبة مع معاينة القيد قبل الترحيل  
> والفريق بياخد تنبيهات على الاعتمادات والطلبات عشان محدش يفوّت خطوة  
> وكل مستخدم بصلاحية مناسبة أدمن أو مدير مشاريع أو محاسب مشروع  
> والواجهة عربي أو إنجليزي وتختار ثيم يناسب شغلك داكن أو هادي أو فاتح أو ERP  
>  تشغيل المقاولة من الشاشة بقيود بعد الاعتماد 

*(عند TTS: طبّق ق→ء واحذف الترقيم كما في مسار `docs:voice:narrate`.)*

## نقاط القوة (موسَّعة)

| المجال | إيه اللي بيتميّز |
|--------|------------------|
| **توزيع التكاليف / الاعباء والمصروفات غير المباشرة ** | مصروف المراكز الخدمية يتوزّع على **عئود المشاريع**؛ مش «عمومية» بلا صاحب. |
| **إقفال الفترات** | إقفال قائمة الدخل + **أفل الفترة**؛ الترحيل في ربع مئفول للمستثنين فقط. |
| **مراكز تكلفة** | عئود مباشرة + مراكز خدمية؛ توزيع بنسب مع مراجعة قبل الإغلاق. |
| **قيود بعد الاعتماد** | مستخلص / باطن / عهدة / صرف / رواتب / الاعباء والمصروفات غير المباشرة  — **الحفظ ≠ قيد**. |
| **البنوك** | حسابات · شيكات · **تحويل موحّد** (داخلي/خارجي · بنك/إنستاباي). |
| **الرواتب** | أيام · تأمينات/ضريبة مصرية · توزيع على مراكز · إشعار راتب اختياري. |
| **التنبيهات** | جرس للاعتمادات والطلبات مع فتح شاشة المصدر حسب الصلاحية. |
| **الصلاحيات** | أدوار جاهزة (`admin` · `projects_manager` · `project_accountant` · مستخدم) + صلاحيات موديول تفصيلية (عرض/إنشاء/تعديل) + نطاق عئود للمحاسب + إخفاء عناصر قائمة اختيارياً بدون كسر الصلاحية. |
| **عربي / إنجليزي** | واجهة ثنائية اللغة بالكامل؛ التبديل يحفظ تفضيل المستخدم. |
| **الثيمات** | `dark` · `soft` · `light` · **`erp`** (شريط علوي بأسلوب ERP) — تفضيل محفوظ لكل مستخدم. |
