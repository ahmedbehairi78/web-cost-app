عرض تقديمي خارج التطبيق — لقطات حقيقية من الواجهة بعد تشغيل سكربت الالتقاط.

التنقل: الأسهم ← → أو الأزرار بالأسفل · F ملء الشاشة

خريطة التدفق

  • مكتب فني: مشروع → عقد → BOQ → مستخلص عميل
  • تكاليف: فاتورة مشتريات → مخزن 127 → صرف للموقع
  • بنوك / يومية / رواتب / تقارير تكمّل الدورة المالية

الملف النصي التفصيلي: OPERATIONS_FLOWS.md

1 — تسجيل الدخول

شغّل npm run docs:screenshots لتوليد اللقطة

2 — سطح المكتب بعد الدخول

بانتظار اللقطة
  • شريط جانبي بالموديولات
  • موديول واحد نشط في كل مرة
  • الآلة الحاسبة يمكن أن تبقى مفتوحة معه

3 — المكتب الفني

بانتظار اللقطة
  • مشاريع وعقود
  • جداول كميات وأوامر تغيير
  • مستخلصات العميل + كفر Cover-JLL

4 — فاتورة المشتريات

بانتظار اللقطة
  • آجلة أو نقدية
  • أصناف + مخزن مشروع
  • قيد ومخزون معاً عند الحفظ (محلي)

5 — المخازن والصرف

بانتظار اللقطة
  • رصيد مخزن المشروع
  • أمر صرف متعدد الأصناف/البنود
  • إرجاع جزئي عند الحاجة

6 — الأستاذ العام

بانتظار اللقطة
  • فلاتر قبل التحميل
  • يومية + كشف حساب
  • شجرة الحسابات من الإعدادات

7 — البنوك

بانتظار اللقطة
  • كشف حساب بنكي
  • معاملات: حركات + شيكات
  • تحويل موحّد وشيك ISS/CLR

8 — الرواتب

بانتظار اللقطة
  • كشف أيام → تأمينات/ضريبة تلقائياً
  • معاينة قيد قبل الاستحقاق
  • توزيع على مراكز تكلفة

9 — التقارير

بانتظار اللقطة
  • دخل · ميزانية · ميزان · سيولة
  • تكاليف BOQ · ميزانية مقابل فعلي
  • طباعة عبر معاينة موحّدة

مسارات للتحقق السريع

  • فاتورة → زيادة رصيد المخزن → صرف CON-
  • مستخلص: كفر = Sub − استقطاعات − Previous Payments → اعتماد متوازن
  • رواتب: أيام → معاينة → استحقاق

حدّث اللقطات: npm run docs:screenshots
